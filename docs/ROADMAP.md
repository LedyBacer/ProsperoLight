# Roadmap and ideas

[← Back to README](../README.md) · [Open issues](https://github.com/LedyBacer/ProsperoLight/issues) · [Changelog](../CHANGELOG.md)

ProsperoLight aims to make PC game streaming feel natural on a PS5. The ideas below are **potential directions, not announced features, ranked commitments or delivery dates**. Implemented features belong in the README and changelog; active tasks and design discussion belong in GitHub issues.

## Stream experience

- In-stream quick menu for common host actions (for example, Alt+Tab, Escape and monitor selection).
- Fast resume of a previous session and improved recovery from network disconnects.
- Optional Wake-on-LAN and clearer connectivity diagnostics for offline PCs.
- Automatic bitrate selection informed by network conditions **and** the PS5 decoder's actual throughput.
- More helpful latency metrics, with clear separation between software timing and input-to-photon measurement.

## Picture and display

- Better upscaling choices and quality/performance comparisons for 1080p/1440p streams on a 4K TV.
- Simpler VRR mode selection where console/TV capabilities permit it, without hiding whether variable output actually succeeded.
- Better host-display/HDR negotiation and compatibility with virtual display hosts.
- Broader testing across TVs, firmwares, SDR/HDR modes and wired/wireless networks.

## Input, audio and library

- More controller customization, including per-game profiles and remapping.
- Improved touchpad-as-trackpad and motion-control experiences, where supported by the host.
- Investigation of microphone, controller speaker and additional surround-audio paths.
- Library search/favorites and per-app stream preference profiles.
- Optional direct launch from PS5 home-screen tiles, subject to the capabilities of the installed loader.

## Contribute an idea

Before requesting a feature, check [existing issues](https://github.com/LedyBacer/ProsperoLight/issues). Include the user problem, desired behavior, firmware, host type, and any relevant hardware constraints. Hardware testing is especially valuable for display, VRR and controller work.
